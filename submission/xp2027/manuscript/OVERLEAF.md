# Overleaf Build Instructions

This directory is a self-contained provisional Springer Computer Science Proceedings project for XP 2027.

## Upload

1. Create a blank Overleaf project.
2. Upload `main.tex`, `references.bib`, `llncs.cls`, and `splncs04.bst`.
3. Set `main.tex` as the main document.
4. Use pdfLaTeX. Overleaf will run BibTeX automatically.

The included class and bibliography style are unmodified files from Springer's official LaTeX2e Proceedings Template,
version 2.25 dated 3 September 2026.

## Before submission

- Replace the provisional assumptions after the official XP 2027 call is published.
- Confirm the track, page limit, review anonymity, artifact rule, and AI-disclosure rule.
- Confirm both authors' email addresses, ORCID IDs, exact English affiliations, contribution statement, competing-interest
  declarations, and approval of the final version.
- If review is double-blind, create an anonymized submission version rather than deleting author metadata from this source.
