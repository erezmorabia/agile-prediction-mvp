# Overleaf Build Instructions

This directory is a self-contained provisional Springer Computer Science Proceedings project for XP 2027.

## Upload

1. Create a blank Overleaf project.
2. Upload `main.tex`, `references.bib`, `llncs.cls`, and `splncs04.bst`.
3. Set `main.tex` as the main document.
4. Use pdfLaTeX. Overleaf will run BibTeX automatically.

The included class and bibliography style are unmodified files from Springer's official LaTeX2e Proceedings Template,
version 2.25 dated 3 September 2026.
